# The Illicit Syllabus

**Their syllabi. Your education.**

An independent, source-linked university reading-list archive. Discover what universities assign, browse original syllabi and build a self-directed curriculum.

## Prototype

The homepage is a static, mobile-first HTML/CSS/JavaScript site. Search or filter courses, view linked institutional source materials, save readings locally, and export your curriculum as Markdown.

## Visual direction

Literary impressionist and naïve-art-inspired **painted** illustrations with visible brushwork and expressive color; editorial typography and clean, readable content layout. No stock photography or flat-vector substitutes.

## Data policy

All listed courses link to original institutional sources. The early collection is deliberately partial and does not claim to transcribe each full syllabus. Each assigned work must be traceable to a source, and incomplete lists should be marked as such.

## Roadmap

- Expand the verified reading catalog with source and retrieval information.
- Add reading-level search and cross-course comparisons.
- Build customizable, semester-length curricula, progress tracking, and exports.
- Commission or create original painted discipline art.
- Strengthen accessibility, metadata, and source verification.

Not affiliated with the universities listed.
